# Greeting

The first thing a shopper sees in the chat. It invites a free-text description instead of asking a question, so the shopper's first message can already be searchable (and no clarifying turn is spent).

Configured in the workspace's Greeting panel, a single text field. 

```
Hi! Tell me who the gift is for and anything you know about them (an occasion, what they love, your budget) and I'll suggest a few ideas.
```
